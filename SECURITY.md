# Security Policy

## Supported releases

No beta has been published yet. After launch, security fixes will target the
latest beta unless its release notes say otherwise.

## Report a vulnerability

Do not report vulnerabilities or sensitive information in a public issue.

Use **Report a vulnerability** on this repository's **Security** page. If that
option is unavailable, contact the maintainers through the
[55 Studio organization](https://github.com/55studio) and request a private
reporting channel without including sensitive details.

A useful private report includes:

- the Boooply Mail version and Mac architecture;
- the observed behavior and potential impact;
- clear reproduction steps; and
- sanitized logs or screenshots, when relevant.

Use public [Issues](../../issues) only for non-sensitive installation and beta
problems. Never post passwords, tokens, invitation links, mailbox content,
private keys, environment files, or unredacted logs.
